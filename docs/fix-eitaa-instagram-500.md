# رفع ارور ۵۰۰ صفحات ربات ایتا و اینستاگرام روی هاست

## علت

کدهای ماژول «ربات ایتا» و «اینستاگرام» روی هاست هست، اما **جدول‌های دیتابیس آن‌ها ساخته نشده‌اند**. این جدول‌ها با این مایگریشن‌ها ساخته می‌شوند:

- `2026_09_03_000100_create_instagram_integration_tables.php`
- `2026_09_03_000200_expand_instagram_automation_tables.php`
- `2026_09_03_000300_add_publishing_fields_to_instagram_media.php`
- `2026_09_03_100000_create_eitaa_bot_module_tables.php` (جدول‌های `eitaa_bots`، `eitaa_messages`، `eitaa_campaigns`، ...)

چون پروژه قبلاً روی هاست نصب شده (فایل `storage/app/installed.lock` وجود دارد)، نصب‌کننده دیگر اجرا نمی‌شود و این مایگریشن‌های جدید هرگز اجرا نشده‌اند. به همین دلیل هر صفحه‌ای که به این جدول‌ها کوئری می‌زند (داشبورد ایتا، ربات‌ها، مقاصد، کمپین‌ها، گفتگوهای اینستاگرام و ...) با خطای ۵۰۰ مواجه می‌شود.

برای تأیید: در فایل `storage/logs/laravel.log` هاست دنبال عبارت `SQLSTATE[42S02]` و `Base table or view not found` بگردید — مثلاً `eitaa_bots` یا `instagram_conversations`.

## راه‌حل

### اگر هاست SSH دارد

```bash
cd مسیر-پروژه
php artisan migrate --force
php artisan optimize:clear
```

### اگر هاست فقط FTP / File Manager دارد (راه پیشنهادی)

یک فایل کمکی به نام `public/migrate.php` ساخته‌ام. مراحل:

1. **تغییر کلید امنیتی:** فایل `public/migrate.php` را باز کنید و در خط
   `const MIGRATE_KEY = '...'` مقدار `CHANGE-THIS-KEY-9f4c2b7e18d54a06`
   را به یک رشته تصادفی دلخواه تغییر دهید.
2. فایل را در پوشه `public/` هاست (کنار `index.php`) آپلود کنید.
3. در مرورگر این آدرس را باز کنید (KEY را با مقدار خودتان جایگزین کنید):
   ```
   https://دامنه-شما/migrate.php?key=KEY
   ```
   خروجی باید `✅ مایگریشن‌ها اجرا شد` را نشان دهد.
4. **فایل `public/migrate.php` را از هاست حذف کنید.**
5. `Ctrl+F5` بزنید و صفحات ایتا و اینستاگرام را دوباره باز کنید.

## بعد از اجرا

- صفحات `/admin/eitaa` و `/admin/instagram` باید بدون خطا باز شوند.
- برای ایتا: در صفحه «ربات‌ها» توکن ایتایار (eitaayar.ir) را ثبت و تست کنید؛ تا وقتی «حالت آزمایشی» روشن است پیام‌ها شبیه‌سازی می‌شوند.
- برای اینستاگرام: تنظیمات اتصال در «تنظیمات → اینستاگرام» است.
- زمان‌بر (cron) ماژول ایتا: اگر هاست cron دارد، هر یک دقیقه `php artisan eitaa:cron` را اجرا کنید.
