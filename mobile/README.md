# اپلیکیشن موبایل مرکز رشد و کارآفرینی دکتر بیدی

اپلیکیشن موبایل اندروید و آیفون برای سایت لاراول همین پروژه — ساختهشده با **Expo (React Native)**.
این یک اپ واقعی و نصبشونده است، نه PWA؛ به API سایت (`/api/v1`) متصل میشود.

## امکانات

- 🔐 ورود و ثبتنام با API توکن Sanctum (نشست روی گوشی ذخیره میشود)
- 🏠 صفحهی اصلی: دورههای ویژه، جدیدترین دورهها، محصولات تازه
- 🎓 فهرست و جزئیات دورهها (شهریه، مدرس، سرفصلها، وضعیت ثبتنام)
- 🛍 فروشگاه کتاب و محصولات آموزشی
- 📊 پنل کاربری: دورههای من، درصد پیشرفت، سفارشهای اخیر
- ⚙️ تنظیم آدرس سرور از داخل اپ (برای اتصال به هاست یا سرور محلی)
- 🇮🇷 رابط فارسی راستبهچپ با تم سبز سایت

## اجرا روی گوشی (تست سریع — بدون ساخت)

1. اپ **Expo Go** را روی گوشی نصب کنید (از Play Store / App Store).
2. در پوشهی `mobile`:

```bash
npm install
npx expo start
```

3. با دوربین گوشی QR کد را اسکن کنید — اپ باز میشود.
4. در اپ، از «پروفایل ← تنظیمات سرور» آدرس سایت را وارد کنید:
   - برای تست با سرور محلی: آدرس آیپی رایانه در شبکه، مثلاً `http://192.168.1.10:8000`
     (سرور را با `php artisan serve --host=0.0.0.0` اجرا کنید)
   - برای نسخهی واقعی: آدرس دامنه، مثلاً `https://example.com`

> متغیر محیطی `EXPO_PUBLIC_API_URL` آدرس پیشفرض را تعیین میکند (پیشفرض: `http://localhost:8000`).

## ساخت فایل نصبشونده (APK اندروید)

روی این رایانه SDK اندروید نیست (و رم کافی هم ندارد)، پس از سرویس ابری **EAS Build** استفاده میشود — ساخت روی سرورهای اکسپو انجام میشود و فقط یک بار لاگین لازم است:

```bash
cd mobile
npx eas-cli login        # فقط بار اول — حساب اکسپو رایگان است
bash build-apk.sh        # یا روی ویندوز: build-apk.bat
```

اسکریپت `build-apk.sh` لاگین را بررسی میکند، پروژه را به EAS وصل میکند و ساخت APK را شروع میکند.
در پایان، **لینک دانلود فایل `.apk`** نمایش داده میشود — همان فایل را روی گوشی نصب کنید.

بدون اسکریپت هم همین دو دستور کافی است:

```bash
npx eas-cli login
npx eas-cli build --platform android --profile preview
```

ساخت نسخهی استور (Google Play / App Store):

```bash
npx eas-cli build --platform android   # خروجی AAB برای گوگلپلی
npx eas-cli build --platform ios       # نیاز به حساب توسعهدهنده اپل
```

## ساختار

```
mobile/
├── App.tsx                     # ناوبری و احراز هویت (راستبهچپ)
├── app.json                    # نام، آیکن، شناسه باندل
├── eas.json                    # تنظیمات ساخت ابری
└── src/
    ├── api/client.ts           # اتصال به API، توکن، آدرس سرور
    ├── api/types.ts            # تایپهای پاسخ API
    ├── context/AuthContext.tsx # وضعیت ورود
    ├── components/             # کامپوننتهای مشترک
    ├── navigation/types.ts     # تایپ ناوبری
    └── screens/                # صفحههای اپ
```

## API مورد استفاده (سمت لاراول)

| متد | مسیر | توضیح |
| --- | --- | --- |
| GET | `/api/v1/home` | اطلاعات صفحه اصلی |
| GET | `/api/v1/courses` | فهرست دورهها (صفحهبندی) |
| GET | `/api/v1/courses/{slug}` | جزئیات دوره + سرفصلها |
| GET | `/api/v1/products` | فهرست محصولات |
| GET | `/api/v1/products/{slug}` | جزئیات محصول |
| POST | `/api/v1/auth/register` | ثبتنام |
| POST | `/api/v1/auth/login` | ورود (توکن) |
| GET | `/api/v1/auth/me` | اطلاعات کاربر |
| POST | `/api/v1/auth/logout` | خروج |
| GET | `/api/v1/dashboard` | پنل کاربری (دورهها و سفارشها) |
