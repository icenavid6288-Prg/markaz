# اپلیکیشن دسکتاپ مرکز رشد و کارآفرینی دکتر بیدی

اپلیکیشن دسکتاپ (ویندوز / مک / لینوکس) که به وب‌سایت لاراول همین پروژه متصل می‌شود.
همه‌ی امکانات سایت (دوره‌ها، فروشگاه، پنل کاربری، کوچینگ، پشتیبانی، پنل ادمین و…) در قالب یک برنامه‌ی
مستقل در دسترس است — همان backend و همان دیتابیس؛ فقط پوسته‌ی آن یک اپلیکیشن بومی است.

## امکانات

- 🌐 اتصال کامل به سایت (ورود، نشست، خرید و… دقیقاً مثل مرورگر)
- 📌 آیکن در نوار وظیفه (Tray) با میان‌برهای سریع: دوره‌ها، فروشگاه، پنل کاربری
- 🔔 بستن پنجره = ادامه در پس‌زمینه (نشست شما زنده می‌ماند)
- 📶 بنر «ارتباط با سرور برقرار نیست» + اتصال خودکار هنگام برگشتن اینترنت
- ⚙️ تغییر آدرس سرور از داخل خود اپلیکیشن (بدون نیاز به تغییر کد)
- 🖥️ پنجره‌ای مستقل با آیکن اختصاصی سایت
- 🔗 لینک‌های خارجی (درگاه پرداخت، شبکه‌های اجتماعی و…) در مرورگر پیش‌فرض باز می‌شوند

## پیش‌نیازها

- Node.js 18 به بالا
- سرور لاراول در حال اجرا (در حالت توسعه: `php artisan serve`)

## اجرا در حالت توسعه

```bash
# ۱) وابستگی‌های اپ دسکتاپ را نصب کنید (فقط بار اول)
npm run desktop:install

# ۲) سرور لاراول را روشن کنید (اگر روشن نیست)
php artisan serve

# ۳) اپلیکیشن دسکتاپ را اجرا کنید
npm run desktop
```

اپلیکیشن به صورت خودکار آدرس `APP_URL` فایل `.env` (مثلاً `http://localhost:8000`) را پیدا می‌کند
و به همان وصل می‌شود.

## نصب‌کننده‌ها (اپ کامل، نه PWA)

این اپلیکیشن یک برنامه‌ی دسکتاپ واقعی است (Electron) — فایل اجرایی مستقل با آیکن، نوار وظیفه و
نصب‌کننده؛ هیچ وابستگی به مرورگر یا PWA ندارد.

### ویندوز ✅ (هم‌اکنون آماده است)

```bash
npm run desktop:dist -- --win
```

خروجی: `desktop/release/MarkazDesktop Setup 1.0.0.exe` — همان فایل را دانلود و اجرا کنید؛
نصب‌کننده‌ی کامل با میان‌بر دسکتاپ و منوی استارت است.

### مک (.app) — ساخت روی سیستم مک

فایل `.app` فقط روی سیستم‌عامل مک ساخته می‌شود (الزام اپل). کافیست همین پوشه را روی یک مک ببرید و:

```bash
npm run desktop:install
npm run desktop:dist -- --mac
```

خروجی در `desktop/release/`:

- `MarkazDesktop-1.0.0.dmg` — درگ‌اند‌دراپ به پوشه‌ی Applications
- `MarkazDesktop-1.0.0-mac.zip` — حاوی خودِ `MarkazDesktop.app` (باز کنید و به Applications ببرید)

> چون اپ با گواهی اپل امضا نشده، در اولین اجرا مک هشدار می‌دهد؛ روی آیکن راست‌کلیک کنید و «Open» را بزنید.
> اگر گواهی توسعه‌دهنده‌ی اپل دارید، `"identity": null` را در `desktop/package.json` بردارید تا امضا شود.

### لینوکس (AppImage)

```bash
npm run desktop:dist -- --linux
```

خروجی: `desktop/release/MarkazDesktop-1.0.0.AppImage` — قابل اجرا بدون نصب.

## تغییر آدرس سرور (سایت)

سه راه دارید:

1. **از داخل اپلیکیشن**: روی آیکن نوار وظیفه کلیک راست کنید ← «تنظیمات سرور…» و آدرس سایت
   (مثلاً `https://example.com`) را وارد کنید. تنظیم در `config.json` ذخیره می‌شود.
2. **متغیر محیطی**: قبل از اجرا `DESKTOP_SERVER_URL` را تنظیم کنید.
3. **فایل کانفیگ**: فایل `config.json` داخل پوشه‌ی کاربردی اپ (`userData`) را ویرایش کنید:

```json
{ "serverUrl": "https://example.com" }
```

اگر آدرس ذخیره‌شده وجود نداشته باشد، اپلیکیشن به `APP_URL` پروژه‌ی لاراول متصل می‌شود.

## نکته‌ها

- **درگاه پرداخت**: پرداخت‌هایی که به درگاه خارجی می‌روند در مرورگر پیش‌فرض سیستم باز می‌شوند
  (رفتار امنیتی استاندارد). پرداخت‌های داخلی سایت داخل خود اپ انجام می‌شوند.
- **دانلود فایل‌ها** (مثل گواهی PDF) با دیالوگ استاندارد دانلود سیستم انجام می‌شود.
- **نشان اپلیکیشن**: اسکریپت `npm run desktop:icon` آیکن اپ را از `public/images/pwa-icon.svg`
  سایت می‌سازد و در `desktop/icons/` قرار می‌دهد.

```
├── renderer/
│   ├── settings.html     # پنجره‌ی تنظیمات (آدرس سرور)
│   └── settings.js
├── scripts/
│   └── make-icon.cjs     # ساخت آیکن از SVG سایت
├── icons/                # آیکن‌های تولیدشده
└── release/              # خروجی نصب‌کننده‌ها
```
